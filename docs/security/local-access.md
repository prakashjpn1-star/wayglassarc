# Local access and resource boundaries

Bind to loopback, validate Host/Origin, separate fictional control roles if needed and keep disposable session values out of URLs/logs. File/project/scene selection uses controlled registries and validated relative paths; reject traversal, remote URLs, guest filesystem/network calls and arbitrary host execution.

Bound request bytes/nesting, scene/project/graph size, diagnostic pages, work quotas, artifact memory and retention. Lab controls act only on task-owned processes/files. Invalid data produces a domain error, not an exposed host stack trace.

Geometry/cost/numerical domain checks are correctness limits, not safety certification for real-world equipment or navigation.

The browser uses escaped text, keyboard controls and clear confirmation for deleting disposable test data. Required runtime operation is offline with generated/owned data and no real accounts or external services.
